# Use Cases / Studies

Every case in this section is a real deployment or a public project, and each one links to a public source: a press release, a conference write-up, a hackathon record, or a public GitHub repository. If a claim has no public source, it is not here.

## Cases

| Case | What it is | Date | Source |
| --- | --- | --- | --- |

## Patterns

[Patterns](patterns.md) collects the problems vCon is designed for that do not yet have a public deployment to point to: moving conversation history between providers, privacy compliance, sharing with third parties. That page is labelled as patterns, and each pattern links to the hackathon build or spec section that shows it in practice.

## Add a case

Open a pull request against `use-cases-studies/` in [vcon-dev/vcon-docs](https://github.com/vcon-dev/vcon-docs) with a link to the public source. Say what was done, which vCon features it used, and when. Name an organization only if the public source names it.
