# vCons

A vCon (virtual conversation) is a JSON container for one conversation: who took part, what was said, what has been derived from it, and the files that explain it. It does for conversations what PDF did for documents and vCard did for contacts, so a call, chat or meeting can move between systems as one object. It is being standardized at the IETF as [`draft-ietf-vcon-vcon-core`](https://datatracker.ietf.org/doc/draft-ietf-vcon-vcon-core/), with optional signing and extensions such as lawful basis built on top.
