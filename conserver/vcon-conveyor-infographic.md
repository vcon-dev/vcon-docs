# 👜 The Journey of a vCon

This interactive diagram draws one vCon's trip as a conveyor belt. It starts at the communication system and the adapter that builds the vCon, then follows the Redis ingress queue into a chain: the ledger registration, the transcriber link, the analyze, tag and redact links, and a custom link calling your own systems. It ends at the storage links, the vCon MCP server and the AI assistants that read the finished record.

[Day in the Life of a vCon](day-in-the-life-of-a-vcon.md) walks the same stations in prose, with the configuration for each one. The rules each station follows are in [Concepts](concepts.md).
