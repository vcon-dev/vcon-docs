# Deep Dives

Longer pieces on the reasoning behind vCon's privacy and audit design. For field names and normative rules, use the [Field Reference](../vcons/field-reference.md) and the [Extensions](../extensions/README.md) pages; where one of these pages and a draft disagree, the draft wins.

* [vCon Lifecycle Management using SCITT](vcon-lifecycle-management-using-scitt.md): whitepaper on keeping the lawful basis in the vCon and lifecycle events in a SCITT log. Revised 2026-10-06 against lifecycle-01 and lawful-basis-02.
* [Privacy-First Conversation Management](privacy-first-conversation-management.md): paper on why the legal grounds for processing belong inside the vCon and how a pipeline checks them. Updated for lawful-basis-02.
* [vCons and Increasing End User Agency](vcons-and-increasing-end-user-agency.md): essay, May 2026, on how purpose grants, expiration and SCITT records give people more control, and where they fall short.
* [SCITT: Supply Chain Integrity, Transparency and Trust](scitt-supply-chain-integrity-transparency-and-trust.md): short reference to SCITT (RFC 9943, RFC 9942) and how vCon systems use it. Current as of 2026-10-06.

The [vCon GitHub repository](https://github.com/vcon-dev/vcon) and the [IETF VCON working group](https://datatracker.ietf.org/group/vcon/about/) hold the primary sources.
